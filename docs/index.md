# Desktop Widgets

Draggable, frameless desktop widgets for Windows — a clock, a calendar wired to
live read-only iCalendar feeds, and an email widget — built with Electron and
plain HTML, CSS and JavaScript.

## Features

- **Calendar** — Monday-start month grid with a live events panel, month and
  year navigation, and a hand-rolled iCalendar parser with recurrence support.
- **Clock** — fits itself to its content, with selectable sizes.
- **Email** — recent messages from a connected Gmail account, read-only.
- **Per-widget settings** — right-click any widget for background, opacity,
  size, and position locking.
- **Runs locally** — no servers, no telemetry, no accounts.
